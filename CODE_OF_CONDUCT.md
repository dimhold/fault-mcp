# Code of conduct

## The short version

Be decent. Argue with the code, not with the person who wrote it.

## What is expected

- Assume the other person is trying to get something right.
- Say what you observed and what you expected. A bug report that names a
  profile and a seed is worth more than one that names a feeling.
- Disagree in public, in the thread, with reasons.

## What is not

Harassment, personal attacks, or any of the usual ways of making a place
unpleasant. Also: submitting a report you have not verified, then arguing
about it. This project is about the difference between a real result and a
plausible one, so that particular habit is worse here than elsewhere.

## Enforcement

Reports go to <dimhold@gmail.com>. The maintainer reads them and decides.
That is one person, so expect a human answer rather than a process.
